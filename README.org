#+title: typst-overlay
#+author: Hesam Pakdaman

[[file:demo.gif]]

Render Typst math equations as inline overlays in Emacs. Equations are asynchronously compiled to SVG using the =typst= compiler and displayed on top of the source text. Overlays are visible when the cursor is outside the equation and hidden when the cursor moves inside, revealing the raw source for editing. Overlays are invalidated when the underlying text is modified and restored on the next refresh.

Equations that fail to render get a dotted red underline (face =typst-overlay-error=); move point into one, or hover over it, to see the error. They can also be reported to Flymake (see below).

** Requirements
- Emacs 29.1 or later, built with SVG support (most builds are)
- [[https://typst.app][typst]] compiler available on =PATH=
- [[https://github.com/uben0/tree-sitter-typst][Tree-sitter grammar for Typst]], used to find equations in both modes. It is already installed if you use =typst-ts-mode=; otherwise run =M-x treesit-install-language-grammar=.

** Supported modes
- =org-mode= — renders =$...$= as Typst math, following Typst's rules: =$x$= is inline and =$ x $= is display. Math may nest, as in =$#table($x$)$=. Write =\$= for a literal dollar sign. Math may span lines within a paragraph, and is ignored in code, verbatim and src blocks.
- =typst-ts-mode= — renders all math equations in Typst documents

** Installation
The recommended configuration:
#+begin_src emacs-lisp
  (use-package typst-overlay
    :vc (:url "https://github.com/hesampakdaman/typst-overlay" :rev :newest)
    :custom
    ;; Report equations that fail to compile to Flymake in Typst
    ;; buffers too, not only in org buffers (see below)
    (typst-overlay-use-flymake t)
    ;; Optional: shown values are the defaults
    (typst-overlay-scale 1.0)
    (typst-overlay-max-active-compiles 8)
    :hook ((typst-ts-mode . typst-overlay-mode)
           (typst-ts-mode . flymake-mode)
           (after-save . typst-overlay-save-refresh)))
#+end_src
To render math in org buffers too, add =(org-mode . typst-overlay-mode)= and =(org-mode . flymake-mode)= to =:hook=.

** Usage
Enable the minor mode with =M-x typst-overlay-mode=. To render overlays manually run =M-x typst-overlay-refresh=.

** Flymake
In org buffers, turn on =flymake-mode= alongside =typst-overlay-mode= and equations that fail to compile are reported to Flymake: listed by =flymake-show-buffer-diagnostics= and visited with =flymake-goto-next-error=. No language server checks math in org buffers, so typst-overlay is the only source of these errors there.

In Typst buffers this is opt-in, by setting =typst-overlay-use-flymake= to =t= as in the recommended configuration, since a language server may check them already. Set it to =nil= to never report to Flymake.

Errors are those of the last refresh, so they update when overlays are refreshed, for example on save.

In buffers managed by Eglot, for example with =tinymist=, the language server reports compile errors itself, so typst-overlay leaves Flymake to it rather than report each error twice, whether Eglot starts before or after =typst-overlay-mode=. Equations that fail to render keep their dotted underline either way; move point into one to see its error.

** Configuration
All options are available via =M-x customize-group RET typst-overlay=.
|-------------------------------------+------------------------+--------------------------------------|
| Variable                            | Default                | Description                          |
|-------------------------------------+------------------------+--------------------------------------|
| =typst-overlay-scale=               | =1.0=                  | Equation size relative to the text   |
| =typst-overlay-cache-dir-name=      | =.typst-overlay-cache= | Directory name for cached SVG files  |
| =typst-overlay-max-active-compiles= | =8=                    | Max concurrent compilation processes |
| =typst-overlay-extra-prelude=       | =""=                   | Extra typst prelude code             |
| =typst-overlay-use-flymake=         | =org=                  | Where to report errors to Flymake    |
|-------------------------------------+------------------------+--------------------------------------|
